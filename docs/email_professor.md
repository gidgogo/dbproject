# 2-0. 데이터 수집 방법 관련 교수님 말씀 확인

> 정정일: 2026-11-06 · 상태: 확인 완료, 별도 문의 메일 불필요

교수님은 **데이터 수집 방법은 신경 쓰지 않는다**고 말씀하셨다.
따라서 데이터 수집 방법에 대한 추가 문의 메일을 보내거나 답변을 기다릴 필요가 없다.

KBO 홈페이지 크롤링과 kbodata 활용을 기준으로 작업을 진행한다.
2026-11-06 사용자의 범위 결정에 따라 네이버 문자중계 수집은 제외했다. 이는 교수님 지시와 별개의 프로젝트 범위 결정이다.
실제 데이터 제공 여부와 크롤러 동작 검증은 각 수집 작업에서 확인한다.

기존 초안의 메일 발송 기한(11/6), 팀 단톡 사전 안내 문구, 문의 메일 초안,
답장에 따른 계획 변경 표는 불필요해 삭제했다. 이 문서는 메일 발송·회신 기록이 아니라
교수님 말씀을 반영한 확인 기록이다. 기존 문서 링크를 유지하기 위해 파일명은 그대로 둔다.
