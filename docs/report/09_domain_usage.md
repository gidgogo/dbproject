# 9-부록. 도메인별 사용 컬럼 (자동 생성)

> 논리 도메인은 `erd/domains.csv`, 사용 컬럼은 `erd/domain_columns.csv`. DB에는 DOMAIN 타입 대신
> 기본 자료형 + 컬럼 CHECK 로 구현했다(JPA `ddl-auto: validate` 호환). FK 컬럼은 부모 키가 값을 보장하므로 CHECK를 생략.

| 도메인 | 기본 자료형 | 제약 (VALUE = 컬럼 값) | 설명 | 사용 컬럼 |
|---|---|---|---|---|
| d_team_id | varchar(2) | `CHECK (VALUE ~ '^[A-Z]{2}$')` | 팀ID: KBO 팀코드 2자리 영문 대문자 (OB, LT, SS, HH, LG, HT, SK, WO, NC, KT) | team.team_id, team_season.team_id, player_season.team_id, match.away_team_id, match.home_team_id, match_team.team_id, inning_score.team_id, batter_match.team_id, pitcher_match.team_id, match_event.team_id, season_batting_official.team_id, season_pitching_official.team_id, team_rank_official.team_id |
| d_player_id | integer | `CHECK (VALUE > 0)` | 선수ID: KBO 공식 홈페이지 playerId (예: 76232) | player.player_id, player_season.player_id, player_salary.player_id, batter_match.player_id, plate_appearance.player_id, pitcher_match.player_id, match_event.player_id, season_batting_official.player_id, season_pitching_official.player_id |
| d_match_id | varchar(14) | `CHECK (VALUE ~ '^[0-9]{8}_[A-Z]{4}[0-9]$')` | 경기ID: kbodata 형식 YYYYMMDD_원정팀코드홈팀코드더블헤더 (예: 20250601_OBWO0) | match.match_id, match_team.match_id, inning_score.match_id, batter_match.match_id, plate_appearance.match_id, pitcher_match.match_id, match_event.match_id, match_umpire.match_id |
| d_season | integer | `CHECK (VALUE BETWEEN 1982 AND 2100)` | 시즌: KBO 리그 출범(1982) 이후 연도 | team.first_season, team_season.season, player.draft_year, player.join_year, player_season.season, player_salary.season, match.season, season_batting_official.season, season_pitching_official.season, team_rank_official.season |
| d_inning | integer | `CHECK (VALUE BETWEEN 1 AND 18)` | 이닝: 1~18 (kbodata가 18회까지 지원) | inning_score.inning, plate_appearance.inning, match_event.inning |
| d_count | integer | `CHECK (VALUE >= 0)` | 경기 단위 횟수: 0 이상 정수 (타수, 안타, 삼진 등) | match_team.runs, match_team.hits, match_team.errors, match_team.walks_hbp, inning_score.runs, batter_match.at_bats, batter_match.hits, batter_match.rbi, batter_match.runs, pitcher_match.batters_faced, pitcher_match.at_bats, pitcher_match.pitches, pitcher_match.hits_allowed, pitcher_match.home_runs_allowed, pitcher_match.walks_hbp, pitcher_match.strikeouts, pitcher_match.runs_allowed, pitcher_match.earned_runs |
| d_total | integer | `CHECK (VALUE >= 0)` | 시즌 누적 횟수: 0 이상 정수 | season_batting_official.games, season_batting_official.plate_appearances, season_batting_official.at_bats, season_batting_official.runs, season_batting_official.hits, season_batting_official.doubles, season_batting_official.triples, season_batting_official.home_runs, season_batting_official.total_bases, season_batting_official.rbi, season_batting_official.sac_bunts, season_batting_official.sac_flies, season_batting_official.walks, season_batting_official.intentional_walks, season_batting_official.hbp, season_batting_official.strikeouts, season_batting_official.gidp, season_pitching_official.games, season_pitching_official.wins, season_pitching_official.losses, season_pitching_official.saves, season_pitching_official.holds, season_pitching_official.hits_allowed, season_pitching_official.home_runs_allowed, season_pitching_official.walks, season_pitching_official.hbp, season_pitching_official.strikeouts, season_pitching_official.runs_allowed, season_pitching_official.earned_runs, season_pitching_official.batters_faced, season_pitching_official.pitches, season_pitching_official.complete_games, season_pitching_official.shutouts, season_pitching_official.quality_starts, season_pitching_official.blown_saves, team_rank_official.games, team_rank_official.wins, team_rank_official.losses, team_rank_official.draws |
| d_outs | integer | `CHECK (VALUE >= 0)` | 아웃카운트: 투수 이닝을 아웃 수로 저장 (6⅓이닝 = 19) | pitcher_match.outs_recorded, season_pitching_official.outs_recorded |
| d_rate | numeric(4,3) | `CHECK (VALUE BETWEEN 0 AND 1)` | 비율(0~1): 타율, 출루율, 승률 등 소수 셋째 자리 | season_batting_official.avg, season_batting_official.obp, team_rank_official.win_pct |
| d_slg | numeric(5,3) | `CHECK (VALUE BETWEEN 0 AND 5)` | 장타 비율: 장타율(최대 4.000), OPS(최대 5.000) | season_batting_official.slg, season_batting_official.ops |
| d_era | numeric(6,2) | `CHECK (VALUE >= 0)` | 투수 비율 지표: 평균자책점, WHIP 등 소수 둘째 자리 | season_pitching_official.era, season_pitching_official.whip |
| d_hand | varchar(1) | `CHECK (VALUE IN ('L', 'R', 'S'))` | 투타 방향: L 좌, R 우, S 양(스위치히터, 타격에만 사용) | player.throws, player.bats |
| d_person_name | varchar(30) | `CHECK (length(btrim(VALUE)) > 0)` | 인명: 공백만으로 된 값 금지 | player.player_name, player_season.name_in_season, match_event.player_name_raw, umpire.umpire_name |
